# 简介
ljs-vue3版（下文简称：V3JS），这是一款基于若依分离版后端服务V3.8.5，开发的前端框架。

### 特点
1.它保持了vue2版本的绝大部分功能，并修复了其中的一些问题。

2.它拓展了一些新的组件，开放了一些新的功能。

3.它深度集成了一款重要的依赖插件 [ljs-tools](/ljs-tools)（Vue3 前端工具库与常用组件全家桶，独立发包、任意 Vue3 + Element Plus 项目可用），这将这套框架的稳定性智能性提高了一个档次。


### 您可能会有以下疑惑。
问：V3JS与若依官方的分离版前端框架一样吗？

答：保持了部分基本的若依开发习惯及相关功能。

问：使用V3JS，那后端服务用什么？

答：该框架基于若依分离版后端服务V3.8.5开发，后端代码直接前往若依官方网站下载即可直接使用。

## 后端服务
基于若依分离版后端服务V3.8.5+
