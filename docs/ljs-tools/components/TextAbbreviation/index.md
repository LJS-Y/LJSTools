### 主参数

| 参数  | 类型 | 必填 | 默认值 | 参考值 | 说明 |
| ----- | ---- | ----- | ----- | ------ | --- |
| data | String | √ | | | 传入数据。 |
| mode | String | × | line | | 模式。line：行截断；last：尾截断。 |
| max | Number | × | 3 | | 最大行数，超过则隐藏多余部分，并显示展开按钮。 |
| unit | String | × | px | | 单位，应用于本组件。可使用rem。 |
| lineHeight | Number | × | 30 | | 行高。 |
| fontSize | Number | × | 14 | | 字体大小。 |
