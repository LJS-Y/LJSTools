# 简介
ljs-tools和常用插件。

### 插件基于Element-plus。
### tools。


### 安装
```
npm i ljs-tools -S
```

### 全局引入
```
import 'ljs-tools/index.css';
import LjsTools from 'ljs-tools';
app.use(LjsTools);
```

### 局部引入
```
import 'ljs-tools/index.css'; main中引入
import { LJSLoading } from 'ljs-tools';
```
